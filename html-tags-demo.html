HTML 主要标签演示

<h1> 是一级标题；<p> 是段落。

边框、颜色和间距来自 CSS；标签本身描述内容的意义。

文字标签 列表 图片 表格 表单

1. 文字与分组

<section> 把同一主题的内容放在一起；<h2> 是二级标题。

电影卡片：哪吒

<article> 表示独立内容项；<h3> 是这里的三级标题。

这段文字很重要：strong；这段文字需要强调：em。

<div> 是通用分组容器，没有特定语义。

时长：110 分钟。<span> 只标记一小段内容，此处用 CSS 改变颜色。

第一行
第二行：<br> 在段落内部换行。

<hr> 表示主题分隔，浏览器通常显示为横线。

2. 列表

<ul> 无序列表；每一项使用 <li>：

  • 哪吒
  • 你好，李焕英

<ol> 有序列表，浏览器自动添加编号：

  1. 选择电影
  2. 观看电影
  3. 写观影笔记

<dl> 名称与说明列表；<dt> 名称，<dd> 说明：

HTML
描述网页内容和结构。
CSS
设置网页外观和布局。

3. 图片与说明

<figure> 将图片与说明分组；<img> 显示图片，src 指定来源，alt 提供文字描述。img 没有结束标签。

table 表格；thead 表头区域；tbody 数据区域；tr 行；th 表头单元格；td 数据单元格。

5. 表单：可以实际操作

form 收集输入；label 给控件命名；input 输入框；select 下拉菜单；textarea 多行输入。

观看状态：fieldset 分组，legend 给组命名

提交时，name 成为参数名。GET 会把输入放入地址栏，例如 ?username=小明&movie=nezha。本示例只展示提交机制，不保存数据。

aside：补充提示

点击导航可以跳转到各节；点击“姓名”标签可以聚焦输入框；留空姓名并提交，浏览器会提示填写。

<footer> 页面结尾信息。学习 HTML 时，可以同时对照源码和浏览器显示效果。
